🚑 RescueAid – Offline Emergency Guidance System
📌 Problem Statement

In remote and underserved regions, medical emergencies often occur where:

Internet connectivity is unavailable

Medical professionals are not immediately accessible

During the critical “Golden Hour”, untrained bystanders are often the only source of help. However, lack of medical knowledge and real-time guidance significantly increases the risk of preventable fatalities.

RescueAid addresses this gap by providing a fully offline-capable emergency guidance system designed specifically for non-medical individuals.

💡 Solution Overview

RescueAid is a Progressive Web Application (PWA) built with an offline-first backend architecture that provides:

Symptom-based decision support

Step-by-step emergency instructions

Offline video guidance

AI-inspired severity scoring mechanism

Multilingual emergency assistance

Voice-guided support

Emergency logging system

The system ensures accessibility even in rural, disaster-prone, and low-connectivity environments.

🧠 System Architecture

User selects emergency symptoms.

Backend decision engine evaluates input.

AI-inspired severity score is calculated.

Appropriate instructions + contextual video guidance are returned.

Voice assistance reads out emergency steps.

Emergency event is logged for future analysis.
